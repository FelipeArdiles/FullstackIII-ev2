# Arquetipo Maven – BFF Innovatech

Genera un Backend For Frontend con Spring Web y WebClient.

```bash
mvn install
mvn archetype:generate \
  -DarchetypeGroupId=cl.duoc.innovatech \
  -DarchetypeArtifactId=innovatech-bff-archetype \
  -DarchetypeVersion=1.0.0 \
  -DgroupId=cl.duoc.bff -DartifactId=bff-demo -Dversion=1.0.0-SNAPSHOT
```
