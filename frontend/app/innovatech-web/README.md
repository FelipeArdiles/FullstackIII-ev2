# Innovatech Web (React + Vite)

Interfaz para gestionar proyectos y capacidad de recursos humanos vía BFF.

## Requisitos

- Node 18+
- BFF en `http://localhost:8080`
- Microservicios en 8081 y 8082

## Ejecución

```bash
npm install
npm run dev
```

Abrir http://localhost:5173

## Paquetes NPM locales

- `@innovatech/ui-button`
- `@innovatech/ui-project-card` (Observer)
- `@innovatech/ui-capacity-form` (Composite)
